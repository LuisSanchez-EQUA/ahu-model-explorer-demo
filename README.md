# AHU Model Explorer — static prototype

This is a self-contained, browser-only prototype of the AHU Model Explorer.
It contains two preloaded dummy scenarios and needs no Python runtime or web
server. Publish this folder with GitHub Pages and open the resulting URL in a
browser.

The application is read-only. Its data in `data/` was generated from the
approved dummy PRN bundles in the private developer repository. To change or
add a scenario, regenerate the static data in the developer workspace and
replace the corresponding file here; end users cannot upload files.

Do not add confidential, client-specific, or unapproved simulation data to
this prototype repository.
